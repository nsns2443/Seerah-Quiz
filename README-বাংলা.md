# সীরাত কুইজ — Android App (WebView wrapper)

এই ফোল্ডারে আপনার "সীরাত কুইজ ও গিফট পোর্টাল" ওয়েবসাইটের একটা Android অ্যাপ ভার্সনের
সম্পূর্ণ সোর্স কোড আছে। এটা আগের LifeManager অ্যাপের মতোই একটা **WebView wrapper** —
অর্থাৎ অ্যাপটা মূলত আপনার ওয়েবসাইটটাকেই একটা নেটিভ অ্যাপের খোলসের ভেতরে দেখায়।

## এই প্রথম ভার্সনে যা আছে

- আপনার কুইজ পোর্টাল ফোনে একটা আলাদা অ্যাপ আইকন থেকে সরাসরি খোলা যাবে
- ব্যাক বাটন দিয়ে ওয়েবসাইটের ভেতরে পেছনে যাওয়া যাবে
- ইন্টারনেট না থাকলে একটা সুন্দর বার্তা দেখাবে, "আবার চেষ্টা করুন" বাটন সহ
- WhatsApp গ্রুপ লিংক, ফোন/ইমেইল লিংকে ক্লিক করলে ফোনের নিজের অ্যাপ দিয়ে খুলবে
- অ্যাপ আইকন হিসেবে আপনার সাইটের লোগোটাই বসানো আছে

## এই ভার্সনে যা নেই (পরে যুক্ত করা যাবে)

- হোমস্ক্রিন widget (যেমন LifeManager-এ ছিল)
- নোটিফিকেশন/রিমাইন্ডার
- PDF ডাউনলোড বাটনগুলো (লিডারবোর্ড/রিজাল্ট PDF) সাধারণ WebView-এর ভেতরে ঠিকমতো কাজ
  না করতে পারে — এটা স্বাভাবিক Android WebView-এর একটা সীমাবদ্ধতা। PDF লাগলে আপাতত
  Chrome ব্রাউজারে সাইটটা খুলে ডাউনলোড করলে ভালো কাজ করবে।

## কীভাবে বিল্ড করবেন (APK বানাবেন) — GitHub দিয়ে

আপনি যেভাবে LifeManager অ্যাপটা GitHub দিয়ে বানিয়েছিলেন, এখানেও ঠিক সেভাবেই একটা
**GitHub Actions workflow** (`.github/workflows/build-apk.yml`) যোগ করে দেওয়া আছে —
এটা স্বয়ংক্রিয়ভাবে APK বানিয়ে দেবে, Android Studio ছাড়াই।

1. GitHub-এ একটা নতুন (খালি) repository তৈরি করুন — যেমন `seerah-quiz-app`।
2. এই `SeerahQuizApp` ফোল্ডারের **সব ফাইল** (লুকানো `.github` ফোল্ডারসহ) সেই
   repository-তে আপলোড/পুশ করুন। (GitHub ওয়েবসাইট থেকে "Add file → Upload files"
   দিয়ে পুরো ফোল্ডার টেনে ছেড়ে দিলেও হবে — শুধু `.github` ফোল্ডারটা যেন বাদ না যায়।)
3. আপলোড হয়ে গেলে repository-র উপরে **Actions** ট্যাবে যান। "Build APK" নামে একটা
   workflow নিজে থেকেই রান হওয়া শুরু করবে (না হলে ডান পাশ থেকে "Run workflow" চাপুন)।
4. ২-৩ মিনিট পর রান শেষ হলে সেই রানের পেজে নিচের দিকে **Artifacts** অংশে
   `SeerahQuiz-debug-apk` নামে একটা ZIP পাবেন — ডাউনলোড করে আনজিপ করলে ভেতরে
   `app-debug.apk` পাবেন। এটাই আগের LifeManager-APK.zip-এর মতো ফাইল — ফোনে
   ইন্সটল করে নিন।

### বিকল্প উপায় — Android Studio দিয়ে (যদি GitHub না চান)

1. [Android Studio](https://developer.android.com/studio) ইন্সটল করুন।
2. Android Studio খুলে **Open** করুন এবং এই `SeerahQuizApp` ফোল্ডারটা সিলেক্ট করুন।
3. প্রথমবার খুললে Android Studio নিজেই ইন্টারনেট থেকে প্রয়োজনীয় সব কিছু (Gradle,
   লাইব্রেরি) ডাউনলোড করে নেবে — কিছুক্ষণ অপেক্ষা করুন ("Gradle sync" শেষ না হওয়া পর্যন্ত)।
4. উপরের মেনু থেকে **Build → Build Bundle(s) / APK(s) → Build APK(s)** চাপুন।
5. বিল্ড শেষ হলে নিচে একটা নোটিফিকেশনে "locate" লিংক আসবে — সেখানে ক্লিক করলে
   `app-debug.apk` ফাইলটা পাবেন।

## সাইটের লিংক বদলে গেলে

ভবিষ্যতে যদি Apps Script-এ নতুন "Deploy" করে নতুন লিংক পান (ঠিকানার শেষে `/exec`),
তাহলে `app/src/main/java/com/azharul/seerahquiz/MainActivity.java` ফাইলের উপরের
দিকে `SITE_URL` লাইনটা বদলে নতুন লিংক বসিয়ে আবার Build করলেই হবে। ওয়েবসাইটের ভেতরে
(Code.gs / HTML) যেকোনো পরিবর্তন করলে অ্যাপে এমনিতেই সাথে সাথে দেখা যাবে — অ্যাপ
আবার বিল্ড করার প্রয়োজন নেই, কারণ অ্যাপটা লাইভ ওয়েবসাইটই দেখায়।
